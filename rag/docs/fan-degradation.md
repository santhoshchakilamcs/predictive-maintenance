# Fan Degradation (SAMPLE document written for this demo project. Not an OEM manual.)

## Symptoms
Reduced fan efficiency, higher fan speed for the same thrust, and increased vibration at fan rotational frequencies. Bypass ratio trends downward over time.

## Likely causes
Fan blade erosion, foreign object damage (FOD) nicks, or fan case wear increasing clearances.

## Recommended actions
1. Inspect fan blades for nicks and erosion; blend minor damage per limits.
2. Check vibration spectrum for fan-order peaks before condemning the module.
3. If vibration exceeds limits or efficiency loss is accelerating, remove the engine for fan module work.
